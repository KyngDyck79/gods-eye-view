# Data sources

The full provider register is in [DATA_SOURCES.md](DATA_SOURCES.md). It lists
each source's URL, cost, key, rate limit, license, attribution and the date
it was verified. The same information is shown live in the app under
**SYSTEM**. The spec calls this file `DATA-SOURCES.md`; the existing project
already used `DATA_SOURCES.md`, so this page points there.
